# Show an unread-messages badge on the Chat tab

## Description
Serves US-3 (keep household members aware of what is happening). While someone is on the Chores tab, new messages from roommates are easy to miss. This slice adds a small red count badge to the Chat tab for messages from roommates that arrived since the chat was last open, and clears it when the Chat tab is opened. Out of scope: push notifications, per-message read receipts, a badge on the app icon, and counts across more than one household.

## Specs
- New file `frontend/src/utils/unread.ts` exports these functions. Messages are the existing `Message` type (`{ id, username, messageText, timestamp, ... }`, with `timestamp` an ISO string).
  - `latestTimestamp(messages)` returns the newest valid `timestamp` string, by time and not by array position, or `null` when there are no messages or none has a valid timestamp.
  - `countUnread(messages, username, lastSeen)` returns how many messages were sent by someone other than `username` (ignoring letter case) and have a `timestamp` strictly later than `lastSeen`. `lastSeen` is an ISO string, or `null`, which means every message from a roommate counts. A message whose timestamp is not a valid date is not counted.
  - `advanceUnread(state, messages, username, chatOpen)` returns the next state `{ started: boolean, lastSeen: string | null, unread: number }`. The starting state is `{ started: false, lastSeen: null, unread: 0 }`.
    - The first call (`started` is false): messages that are already there are history, not unread. It returns `started: true`, `lastSeen` set to `latestTimestamp(messages)`, and `unread: 0`.
    - Later calls with `chatOpen` true: `lastSeen` becomes `latestTimestamp(messages)` (it is kept when there are no messages) and `unread` is 0.
    - Later calls with `chatOpen` false: `lastSeen` is unchanged and `unread` is `countUnread(messages, username, lastSeen)`.
    - It does not change `state` or `messages`.
  - `badgeText(count)` returns `''` for 0, for a negative number, and for a count that is not a finite number; the number as text for 1 to 9; and `'9+'` for 10 or more.
- `frontend/src/hooks/useUnreadMessages.ts` exports `useUnreadMessages(token, inviteCode, username, chatOpen, onSessionExpired)` and returns the unread count. It loads messages with `getMessages` on mount and every 5 seconds, passes them through `advanceUnread`, and calls `onSessionExpired` when a request fails with the `UNAUTHENTICATED` error code. When `chatOpen` becomes true the count is 0 right away.
- `frontend/src/components/TabBar.tsx`: a `Tab` may have a `badge?: string`. A non-empty badge is drawn as a small red pill with white text at the top right of the tab's icon. An empty or missing badge draws nothing. When a badge shows, the tab's accessibility label is `<label>, <badge> unread`.
- `frontend/src/screens/MainTabs.tsx` passes `badgeText(unread)` to the Chat tab, and `chatOpen` is true while the Chat tab is selected.

## Requirements
- Reuse the existing `getMessages`; add no server routes, database changes or dependencies.
- `frontend/src/utils/unread.ts` uses `import type` for types and does not import React Native, so its tests run in plain Node.
- The tab bar looks and behaves as before when there is no badge, and the chat screen's own message loading is unchanged.
- Existing tests in `tests/` must keep passing. New tests need no database or network.

## Acceptance criteria
1. `countUnread` counts the messages from roommates that are later than `lastSeen`.
2. `countUnread` never counts the signed-in user's own messages, even when their name differs in letter case.
3. A message exactly at `lastSeen` is not unread, and a message one millisecond later is.
4. When `lastSeen` is `null`, every message from a roommate counts.
5. Messages with an invalid timestamp are ignored by both `countUnread` and `latestTimestamp`.
6. `latestTimestamp` returns the newest timestamp whatever the order of the messages, and `null` for no messages.
7. On its first call `advanceUnread` treats the messages already present as history (`unread` 0), then counts only newer roommate messages while the chat is closed.
8. While the chat is open `advanceUnread` sets `unread` to 0 and moves `lastSeen` to the newest message, so the same messages are not unread again after the user leaves the chat.
9. `badgeText` shows nothing for 0 and for invalid counts, the number for 1 to 9, and `9+` for 10 or more.
10. `advanceUnread` does not modify the state or the messages it is given.
